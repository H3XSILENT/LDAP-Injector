## About

LDAP Injector is a GO command-line tool to test injection vulnerabilities in the **Lightweight Directory Access Protocol** (LDAP). This project was developed as part of a pratical study based on the IPPSEC "Golang For Hacker" playlist, on a HackTheBox Ghost machine, whith the aim of undestanding the mechanics of attacks on service and login bypass and tool construction offensives in GO.
